# Embedded fonts

Space Grotesk Regular, Medium, and Bold come from the system `otf-space-grotesk` package. Space Mono Regular and Bold come from `ttf-space-mono-nerd`, are subset to Ryoport's text and symbol ranges, and are renamed to Space Mono. Both families are distributed under the SIL Open Font License 1.1 in `OFL.txt`.

Run `tools/fonts/build.sh` from any directory to reproduce the embedded files from the installed source fonts.
