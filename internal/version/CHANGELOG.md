# Changelog

## v1.0.0

- Brings machines, passthrough machines, servers and consoles into one window.
- Has its own look, Lithic: flat cut-stone planes, a stone for each state and a view from above of the whole fleet.
- Replaces the old Quickshell interface and shell engine with a native app.
- Follows the current Ryoku palette.
- Adds a command palette for finding resources and actions.
- Keeps jobs, alerts and recent changes together in the activity log.
- Checks, downloads and applies its own updates when the install method supports it.
