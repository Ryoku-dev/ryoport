# Changelog

## v1.0.0

- Brings machines, passthrough machines, servers and consoles into one window.
- Has its own look, Lithic: flat cut-stone planes, a stone for each state, and a Now board that shows what needs you, what is running, your pinned machines and how this computer is doing.
- Replaces the old Quickshell interface and shell engine with a native app.
- Follows the current Ryoku palette.
- Adds a command palette for finding resources and actions.
- Keeps jobs, alerts and recent changes together in the activity log.
- Lets you pin any machine, server or console; pinned ones get their own group and tiles on the Now board.
- Opens catalogue systems in a dialog with their releases and editions.
- Scrolls at the speed of your fingers on a trackpad, also on fractionally scaled screens.
- Checks, downloads and applies its own updates when the install method supports it.
